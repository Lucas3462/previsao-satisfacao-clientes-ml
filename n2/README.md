# N2 - Desenvolvimento futuro

Esta pasta preserva o material de modelagem para uma etapa posterior. Ela não faz parte da entrega atual do primeiro bimestre.

O conteúdo inclui os notebooks de modelagem e avaliação, os pipelines de Logistic Regression, Decision Tree e Random Forest, além dos resultados e modelos serializados anteriormente gerados. Nada desse material é apresentado como resultado do N1.

Para executar o N2 futuramente, instale [n2/requirements.txt](requirements.txt) a partir da raiz e revise os caminhos dos notebooks conforme a etapa de desenvolvimento.
